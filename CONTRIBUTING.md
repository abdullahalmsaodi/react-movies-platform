# Contributing

Contributions are welcome! Whether it's fixing bugs, improving the UI, or suggesting new features, your help is appreciated.

## How to Contribute

1. **Fork** the repository.
2. **Clone** your fork:
   ```bash
   git clone https://github.com/Abdullah-Almsaodi/react-movies-platform.git
   ```
3. **Create a branch:**
   ```bash
   git checkout -b feature/your-feature
   ```
4. **Install dependencies:**
   ```bash
   npm install
   ```
5. **Make your changes** and test them locally:
   ```bash
   npm run dev
   ```
6. **Commit your changes:**
   ```bash
   git commit -m "feat: describe your changes"
   ```
7. **Push your branch** and open a Pull Request.

## Guidelines

- Follow the existing code style and project structure.
- Keep changes focused and avoid unnecessary modifications.
- Use clear, descriptive commit messages.
- Test your changes before submitting a Pull Request.
- Provide a brief description of your changes.

## Reporting Issues

If you find a bug or have a feature suggestion, open an issue with a clear description and steps to reproduce it.

Thank you for contributing :)
